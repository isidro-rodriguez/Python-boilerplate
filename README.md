# python-boilerplate

Boilerplate moderno y minimalista para proyectos de Python.

## Características

- Estructura `src/` layout
- Gestión de dependencias con `uv`
- Linting y formateo con `ruff`
- Tests con `pytest`
- Configuración lista para VS Code

## Instalación

```bash
uv venv
uv sync --group dev
```

## Uso

```bash
uv run python -m python_boilerplate
```

## Tests

```bash
uv run pytest
```
